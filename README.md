# ES 114 · Probability, Statistics and Data Visualization (2025)

Course website for ES 114 Probability, Statistics and Data Visualization at IIT Gandhinagar, Semester II 2024–25:
<https://nipunbatra.github.io/psdv25/>

The site is a [Quarto](https://quarto.org) website in the same design as
[ES 667 Deep Learning](https://nipunbatra.github.io/dl-2026/). GitHub Actions renders it and publishes it to the
`gh-pages` branch (`quarto publish gh-pages`) on every push to `main`.

| File | Contents |
|---|---|
| `index.qmd` | Home: course facts, course record, module overview, questions, references, teaching assistants |
| `schedule.qmd` | Lectures: one row per lecture with slides, handwritten slides, cheat sheets, videos, notebooks and apps |
| `assessment.qmd`, `_dates.qmd` | Grading, attendance and leave, assignments and every dated event |
| `exposition.qmd` | The exposition assignment (Assignment 4) |
| `videos/videos.qmd` | All exposition submissions, generated from `videos/exposition_assignment.csv` |
| `faq.qmd` | All questions |
| `slides/` | Handwritten and lecture slides (PDF) and the transformation notebook |
| `lectures.qmd`, `grading.qmd`, `tentative.qmd` | Redirects from old URLs |
| `styles.scss`, `course.scss` | Shared theme (`styles.scss` is identical to dl-2026) and small additions |
| `rail.html`, `course-theme.html`, `course-tools.html` | Side rail, light and dark switch, footer, copy-link buttons and date handling |

Preview locally with `quarto preview`.
